Recommended starting points

Start with a short sample before processing a large batch. These are starting points, not guarantees of size or quality.

  • Everyday playback: MP4, H.264 CRF 23, Medium, original resolution/frame rate, AAC stereo 192 kbps.
  • Smaller files: HEVC CRF 28; lower the number if you see artifacts. Confirm HEVC support on your player.
  • NVIDIA offline encoding: try HEVC NVENC, CQ 23, P6, HQ, spatial AQ strength 8 and lookahead 16 where supported. Use P4 or Auto options for a simpler starting point. GPU and driver limits still apply.
  • Audio preservation: MKV with original audio copy; add AAC stereo 192 kbps as a second output for portable playback. For Dolby Digital 5.1, try AC-3 448–640 kbps.
  • HDR and subtitles: inspect a source first. Choose HDR10 for a compatible HDR display, SDR for an SDR display, and Auto processing. Keep subtitles soft when possible; burning is permanent and follows crop/resize.

Quick presets set only their core fields. Review HDR, subtitle and per-track settings separately, then save your complete configuration above.

Movie cleanup replaces dots with spaces and removes text after the last standalone year (1800–2099), puts parentheses around that year, and preserves recognized cut/edition labels after it. Without a year, only dots and repeated spaces are cleaned. Source files stay unchanged.

Deinterlace & telecine

Auto mode samples up to three scenes per file. Manual inspection samples the opening 300 frames. Detection is heuristic; possible telecine is reported for review, never automatically decimated.

Use inverse telecine only for consistent 3:2 film cadence at about 29.97/30 fps. Mixed film/video needs individual inspection. Bob doubles the frame rate; keep the frame-rate setting at Original. Processing order: scan correction → HDR conversion → crop → resize → burned subtitles. Requires video encoding.

CPU threads and parallel jobs

Start with 1 job per device type. NVENC uses encoding sessions, not selectable GPU compute threads. CPU and GPU limits are independent and apply across the entire queue, regardless of GPU index. Stream-copy jobs use a CPU slot. Apply changes the queue limits now; starting a batch also applies them. Reducing a limit lets active jobs finish. CPU threads affect newly queued jobs and are an encoder/filter request, not a hard cap on all system threads.

NVIDIA NVENC options

CQ / QP uses the quality slider above. VBR / CBR uses target bitrate. CQ 0 means automatic quality. Multipass runs within NVENC; it is not file-level two-pass encoding. Auto leaves that option to the encoder. Hardware can impose additional limits.

Samples multiple scenes per file before encoding; inspect results for mixed aspect ratios or very dark footage. Cropping requires video re-encoding.

HDR / Dolby Vision conversion

Select a file or browse a sample under the track editors to inspect its HDR metadata.

HDR10 output requires 10-bit HEVC; SDR uses BT.709. Dolby Vision profile 5 requires decoded RPU metadata, libplacebo and Vulkan. Profile 7 / enhancement-layer sources require explicit compatible base-layer-only selection; full FEL reconstruction is not supported. SDR/unknown input is not relabeled as HDR.

Audio & subtitles

Preserve the original, build a compatible mix, or give every track its own outputs.

Source audio tracks

Inspect a representative file to identify languages and track positions. Shared output settings apply once to each included track; use the advanced per-track mode to create multiple outputs from one source.

Audio settings apply to every selected audio track. AC-3 / E-AC-3 support up to 5.1 here. “Convert to 5.1” does not create real surround from stereo.

Tracks to include

Track positions apply across the batch. A required position missing from a file stops the queue; use separate batches for different layouts. Unchecked tracks are omitted in shared mode.

Per-track audio outputs

Inspect a sample file to identify its audio tracks. Rules use audio track positions (track 1, track 2, …) in every file of the batch. Use separate batches for files with different layouts. A required track missing from a file stops the queue.

Each output can copy the original or encode independently. Add an AAC output beside an original copy, for example. Removing every output from a rule drops that source track. Output settings apply only to that output; copy requires original channels.

Subtitles

Conditional English: checks the first source audio track, regardless of output audio selection. A recognized non-English language tag includes one existing tagged English subtitle track as default, preferring full subtitles over forced-only tracks. Unknown language or no English subtitles produces a queue notice. No speech detection, translation or downloads.

Subtitle tracks

Keep adds a selectable soft subtitle stream. Burn renders the track into the video; both can be selected together, and multiple tracks can be burned. Burn-in runs after HDR conversion, crop and resize. Bitmap subtitles default to fitting inside the cropped frame; original-coordinate placement is also available. Rules use subtitle track positions throughout the batch; a missing track stops the queue. Bitmap soft subtitles require MKV. Burned subtitles cannot be turned off during playback.

Keeps the first video track. Forced-only mode uses the source forced flags. Choose all streams or custom track selection for other subtitles. MKV preserves text and bitmap soft subtitles; MP4 / MOV / WebM need compatible text subtitles. Burned tracks become part of the video.

SRT files are saved beside the completed video using its final basename, language and source track number. Bitmap tracks need OCR; automatic export skips them with a notice. SRT preserves text and timing, but may lose source styling.

Email notifications

Passwords are kept only in server memory for this session. Set FRAMEFORGE_SMTP_PASSWORD for persistent credentials. Email settings and delivery history are stored locally.
